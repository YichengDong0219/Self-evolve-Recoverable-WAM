# 08 · 评测视频与失败分析（2026-10-31）

- `render_eval_queue.sh` / `sync_eval_videos.sh` / `eval_video_index.py` / `make_focus_pairs.sh`：用逐位重放把全部评测渲染成视频（398 条），并建立索引和同 seed 对照视频。
- `failure_phase.py`：按每 48 步的杯子位姿和夹爪开合，判断失败发生在流程的哪一步（挂杯失败 / 交接失败 / 其他）。
- 恢复指标：成功且步数 > 400（专家演示约 340 帧，策略一次成功最多 374 步），并用"右手合爪 ≥ 2 次"复核。
  恢复率 = 掉落 episode 中最终成功的比例：base 0/46，E3000 0/27，M3000 1/37。
- 关键 case：M3000 seed 160082 第一次挂失败、杯子落桌，第 473 步重新抓起，第 551 步挂上；同 seed 的 E3000 从不重新抓杯。
- M3000 失败中 46/48 会反复重抓，但后续 153 次抓取里只有 19% 把杯子抬起来。
