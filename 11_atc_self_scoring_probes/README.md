# 11 · ATC：WAM 自评探针（分支 `atc-self-scoring-probes`，2026-11-21 起，进行中）

## 背景
11-21，用户与 senior 定了新方向：
- 不再用 cuRobo 接管 + SFT；
- 让策略自己 rollout，训练 Q / value 头；
- 测试时对每个 chunk 采多个候选，挑最能推进任务的那个（TTS），拼出成功的整条轨迹，再蒸馏回策略，循环往复。

我们推荐的具体版本叫 **ATC（Alternatives Teach Consequences，备选动作教后果）**，名字对应 FACT 的 “Failures Teach Consequences”：
1. WAM 用自己对候选动作后果的想象来打分；
2. 在仿真里，把同一状态下真实执行过的多个备选动作当作“只训后果”的数据，把想象训准；
3. 然后闭环：成功的整局教行为和后果，失败局和备选动作只教后果。

## 假设
- **H1** 冻结的自评不可靠。普通训练里每个状态只出现一个动作，所以在决定成败的状态上，模型对不同候选想象出的结局差别很小，或者与真实结局对不上。
- **H2** 用真实执行过的备选动作只训“后果”部分，能让自评在没见过的状态上明显变准。要胜过的对照有三类：冻结特征小头、原版 FACT value、PRM 看想象画面打分。
- **H3** 闭环中误选率逐轮下降。蒸馏后不开 TTS 时，整局成功率逐轮上升，并超过“同等数量自身成功轨迹 SFT”。
- **H4**（后期）后果式打分更容易跨任务泛化。

本阶段只做 CPU 分析和单卡推理，不训练 WAM。协议见 [PROTOCOL.md](PROTOCOL.md)，开跑前已冻结并单独提交；相关工作见 [RELATED_WORK.md](RELATED_WORK.md)。

## 数据
- 任务 place_mouse_pad。第一轮 DPO 的分支库：R2 策略的 188 个失败状态。
  - 测试 53 个状态：22 个 place、31 个 recovery；
  - 每个状态 8 个策略候选，部分状态另有 1 个 cuRobo 候选，共 1682 个候选 chunk。
- 标签 = 该 chunk 之后续跑的成功率。多数策略候选只有自身那一次结局（n = 1），部分有 5 次。
- 下表 “±” 后面方括号里的是状态级 bootstrap 95% CI。

## 结果

### 复现核对（通过）
新脚本重算的 11-14 数字完全一致：
- R2 value 在测试集上的 pair_acc 为 0.638；
- ridge/fs 头的 BoN-8：0.294 → 0.381（+0.087）。

### P1 价值分解：打分反映的是“状态好坏”还是“候选好坏”？
| 打分 | 状态间 Spearman | 状态内 Spearman（平均） | 打分方差中状态间占比 |
|---|---|---|---|
| R2 value | 0.08 [−0.06, 0.21] | 0.09 [0.02, 0.16] | 0.88 |
| ridge/fs（FACT 特征，用标签训） | 0.59 [0.48, 0.68] | 0.20 [0.13, 0.27] | 0.79 |
| 标签本身 | — | — | 0.59 |

- **R2 value**：状态间和状态内几乎都没有信息。预先写定的“只学到状态好坏”需要状态间 CI 下界 > 0，这里不满足。R2 训练时 value 损失为 0，这个结果与此一致；原版 FACT 见 G1。
- **用标签训出的小头**：主要学到的是“哪个状态难”，区分同一状态内不同候选的能力弱得多。

### P2 完美后果的上限
用特权信息：把候选 chunk 结束那一刻鼠标相对垫子的真实位置等信息直接给打分器，看能挑多准。

| 打分（测试 53 个状态） | BoN-8 增益 | 占含噪上限 | place | recovery |
|---|---|---|---|---|
| R2 value | +0.061 [−0.013, 0.131] | 26% | +0.030 | +0.083 |
| ridge/fs（FACT 特征） | +0.087 [0.033, 0.146] | 38% | +0.120 | +0.064 |
| 固定规则（真实末端位置，不拟合） | +0.082 [0.032, 0.136] | 36% | +0.146 | +0.037 |
| ridge（真实末端特征） | +0.108 [0.058, 0.166] | 47% | +0.148 | +0.080 |

- 含噪上限：random 0.294 → oracle 0.525，增益 0.231。place 0.489 → 0.709，recovery 0.156 → 0.394。
- 固定规则不需要拟合，所以也在全部 188 个状态上算了：增益 +0.119 [0.082, 0.154]，占上限 43%；其中 place 59%，recovery 22%。
- 在 place 状态，chunk 末端的真实位置能拿到约 2/3 的含噪上限；在 recovery 状态只有 15–34%，因为结局主要在之后的重试中才决定。
- FACT 特征小头和“真实末端位置”打分的增益，差距在噪声范围内。

**判读**：在这批鼠标失败状态上，用“一个 chunk 后的后果”打分，瓶颈主要不在想象精度，而在于“一个 chunk 后的后果还决定不了最终结局”。所以在这个数据上，H2（把想象训准）的提升空间有限；需要更长视野的价值，或者换成后果更能决定结局的任务。

### P3 挑选空间（8 个策略分支各自的结局）
| | 状态数 | 单次成功率 | 8 次里至少成一次 | 8 次全失败的状态 |
|---|---|---|---|---|
| 全部 | 188 | 0.26 | 0.65 | 66 |
| place | 83 | 0.37 | 0.81 | 16 |
| recovery | 105 | 0.18 | 0.52 | 50 |

### P4 去掉标签噪声后的挑选空间
在 183 个状态的复查候选上做（平均每个状态 2.8 个候选，每个有 5 次结局）：

| 挑法 | 成功率 | 比随机高 |
|---|---|---|
| 随机 | 0.19 | — |
| 用其中 2 次结局挑、另 3 次评（无偏） | 0.25 | +0.062 [0.041, 0.084] |
| 按 5 次结局直接取最大 | 0.35 | +0.16 |

含噪的“上限”明显偏乐观，上面各表的“占上限比例”因此偏低。
